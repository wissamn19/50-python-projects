## 📖 Why This Repo Exists

I'm learning Python with a clear goal: becoming a Machine Learning Engineer. Tutorials alone don't build real skill — **building does**. This repo is my structured path from absolute basics to advanced, real-world Python: file handling and OOP first, then APIs and databases, then web frameworks, machine learning, and deployment.

Every project is self-contained, documented, and runnable. Each one took me one step further.

## 🚀 How to Run Any Project

```bash
# Clone the repo
git clone https://github.com/wissamn19/50-python-projects.git
cd 50-python-projects

# Navigate to any project
cd 01-beginner/01-number-guessing-game

# Install dependencies (if the project has its own requirements.txt)
pip install -r requirements.txt

# Run it
python main.py
```
