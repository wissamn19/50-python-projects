# Number Guessing Game

> loops, conditionals, random module, stats tracking

## Overview
This project is a simple number guessing game built with Python. The program generates a random number, and the player must guess it. After each guess, the game provides feedback by telling the player whether the guessed number is too high or too low. The game continues until the correct number is guessed, while also keeping track of the total number of attempts made by the player.

## Concepts Practiced
- loops
- conditionals
- random module
- stats tracking

## What I Learned
Through this project, I learned how to ***work with loops***and understand when and why to use them. I used a **While loop** to keep the game running unti the player guessed the correct number. This helped me understand how loops can be used to repeat actions based on a condition.

I learned how to use Python's **Random** Module, specifically the ***random.randint()*** function, to generate a random number to the game.

Inside, The **While** loop, I kept track of the number of guesses made by the player, which helped me practice using variables and update information during program execution. 

Additionally, I used **If** and **elif** statements to compare the player's guess with the random number and provide feedback on wether the guess was too high, too low, or correct.
